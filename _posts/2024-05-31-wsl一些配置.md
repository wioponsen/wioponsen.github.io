ubuntu20.04相关

1. systemctl，（用于2004版本）
```
git clone https://github.com/DamionGans/ubuntu-wsl2-systemd-script.git
cd ubuntu-wsl2-systemd-script/
bash ubuntu-wsl2-systemd-script.sh
```

2. wsl进程Vmmem占用较高
ref:https://blog.csdn.net/Power_Blogger/article/details/128158694
在用户路径下，创建`Vmmem.wslconfig`，填入内容：
```
#.wslconfig
[wsl2]
memory=3GB //分配给WSL内存3GB
swap=4GB   //设置交换分区4GB
localhostForwarding=true
```
使用命令 `wsl --terminate Ubuntu-20.04`或者 `wslconfig /t Ubuntu-20.04` 关闭wsl项目，重新打开即可。
