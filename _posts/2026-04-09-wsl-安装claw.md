## 一 配置 wsl
1. 配置`.wslconfig`
```ini
[wsl2]
memory=32GB
swap=32GB
processors=12
# 启用镜像网络模式 - 这是最重要的配置
networkingMode=mirrored
# 启用 DNS 隧道，防止 VPN 环境下域名解析失效
dnsTunneling=true
# 强制 WSL 使用 Windows 的 HTTP 代理设置
autoProxy=true
# 启用集成防火墙支持
firewall=true

[experimental]
# 自动回收闲置内存，优化性能
autoMemoryReclaim=gradual
# 支持主机回环地址访问
hostAddressLoopback=true
```

2. 重启wsl
```
wsl --shutdown
```

3. 配置win端口
```
New-NetFirewallRule -DisplayName "OpenClaw-Service" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 18789
Get-NetFirewallRule -DisplayName "OpenClaw-Service" | Format-Table
Get-NetFirewallRule | Where-Object {$_.DisplayName -like "*OpenClaw*"} | Format-Table
Test-NetConnection -ComputerName localhost -Port 18789

# Nat 端口转发，备用
netsh interface portproxy add v4tov4 listenport=18789 listenaddress=0.0.0.0 connectport=18789 connectaddress=(wsl hostname -I)
wsl hostname -I

```

4. 配置本地模型
安装ollama


## 二、配置wsl下openclaw

1. 为了在后续安装脚本运行中避免频繁输入密码，建议为当前用户开启 sudo 免密权限：
`sudo visudo`
在文件末尾添加以下内容（将 spoto 替换为你的实际用户名）：
`spoto ALL=(ALL) NOPASSWD: ALL`
保存并退出（Ctrl+O → Enter → Ctrl+X）。

2. 安装基础工具
`sudo apt install -y curl wget git`
3. 安装 Opencode 工具
Opencode 用于简化后续的复杂配置过程：
```
curl -fsSL https://opencode.ai/install | bash
```
验证安装：
```
which opencode
opencode --version
```
4. 安装 OpenClaw 官方脚本
使用官方提供的一键安装脚本进行部署：
```
curl -fsSL https://molt.bot/install.sh | bash
```
5. 运行初始化向导
安装完成后，运行初始化向导完成基本配置：
```
openclaw onboard --install-daemon
```
按照向导提示完成配置：

选择安全选项（理解风险）
配置工作区目录
设置 Gateway 认证方式
其他基本配置
6. 验证安装
```
which openclaw
openclaw --version
openclaw gateway status
```

7. Select channel (QuickStart)
可以用QQ bot， q.qq.com 扫码登陆，注册机器人，填入即可

8. Search provider
可以使用Ollama的，只需要注册登陆即可

9. 在主机查看dashboard
在主机使用命令：
```
# replace <host> with wsl ip (wsl hostname -I)
ssh -N -L 18789:127.0.0.1:18789 w@<host>

# visit
http://localhost:18789/
```


## 三、问题解决
1. systemctl问题
```
#  sudo vi /etc/wsl.conf
[boot]
systemd=true

# make dirs
sudo mkdir -p /run/user/$(id -u)
sudo chown $USER:$USER /run/user/$(id -u)

# sudo vi ~/.bashrc
export XDG_RUNTIME_DIR=/run/user/$(id -u)
export DBUS_SESSION_BUS_ADDRESS="unix:path=${XDG_RUNTIME_DIR}/bus"

```
启动：
```
openclaw gateway install
openclaw gateway
systemctl --user start openclaw-gateway.service

openclaw gateway status
```
